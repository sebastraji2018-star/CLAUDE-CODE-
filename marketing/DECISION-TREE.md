### 3. ¿Cómo colecto emails?
```

```

**ACCIÓN**: Ir a mailchimp.com → "Sign Up Free"

---

### 4. ¿Cómo proceso pagos?
```
┌─ ¿Prefieres menos comisiones?
│  ├─ SÍ → STRIPE (2.9% + $0.30, mejor)
│  └─ NO → GUMROAD (10% comisión, más simple)
│
└─ Resultado: Tienda online + pagos
```

**Comparativa**:
```
Gumroad: $197 × 90% = $177.30 por venta
Stripe:  $197 - (2.9% + $0.30) = $191.14 por venta

Con 100 ventas:
Gumroad: $17,730
Stripe:  $19,114

Diferencia: $1,384 en favor de Stripe
```

**ACCIÓN RÁPIDA**:
- Si quieres MÁS SIMPLE → Gumroad
- Si quieres MEJOR MARGEN → Stripe

---

### 6. ¿Dónde alojo el contenido (PDFs, plantillas)?

**ACCIÓN**: drive.google.com → Crear carpetas → Subir archivos
