# Plantillas de Análisis de Raíces

Esta carpeta contiene ejemplos completados de análisis académico de canciones/videoclips en relación a sus orígenes literarios, cinematográficos o mitológicos.

## Archivos

### Analisis_Love_Story_Ejemplo.docx

**Descripción:** Ejemplo completo de análisis de "Love Story" de Taylor Swift como adaptación de "Romeo y Julieta" de William Shakespeare.

**Contenido:**
- **Investigación de Raíces:** Identificación de la obra original (Romeo y Julieta, Shakespeare 1595)
- **El Triángulo de Análisis:**
  - La Letra: Tema, premisa y narrativa
  - La Imagen: Elementos visuales del videoclip y cómo expande la narrativa
  - El Conflicto: Conflicto central y resolución visual
- **Veredicto Técnico:** Clasificación como Adaptación y justificación
- **Cambio Técnico Identificado:** Análisis de la MUTACIÓN del final (de tragedia a final feliz)
- **Pitch de Conclusión:** Argumento de 3 minutos sobre si es una adaptación exitosa

**Características:**
- Formato: Documento Word (.docx)
- Extensión: ~2 páginas (según especificaciones)
- Nivel: Universidad
- Tipo: Ejemplo completado para usar como referencia

## Cómo Usar Este Documento

1. **Como referencia académica:** Estudiantes pueden revisar este análisis completo para entender cómo estructurar sus propios análisis.

2. **Como plantilla de estructura:** La organización de secciones puede adaptarse para analizar otras obras (películas, novelas, álbumes musicales, etc.).

3. **Para aprender el marco de análisis:** Observe cómo se aplican los tres componentes del "Triángulo de Análisis" a una obra real.

4. **Para identificar cambios técnicos:** El ejemplo desarrolla en detalle cómo identificar y analizar omisiones, adiciones y mutaciones entre la obra original y la adaptación.

## Requisitos del Análisis

- **Extensión:** Máximo 2 páginas de ficha técnica
- **Obligatorio:** Citar al menos un cambio técnico (omisión, adición, mutación)
- **Secciones requeridas:**
  1. Investigación de Raíces
  2. El Triángulo de Análisis (Letra, Imagen, Conflicto)
  3. Veredicto Técnico (clasificar como Adaptación/Inspiración/Narrativa Original)
  4. Pitch de Conclusión (3 minutos argumentativo)
