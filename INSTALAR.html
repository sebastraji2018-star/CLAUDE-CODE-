Instalación automática para Windows

✅ OPCIÓN 1: Automática (La Más Fácil)

¡SIN ABRIR TERMINAL!
Solo necesitas hacer doble click en un archivo.
Paso 1: Busca el archivo INSTALAR.bat en tu carpeta
Paso 2: Haz DOBLE CLICK en INSTALAR.bat
Paso 3: Se abrirá una ventana de comandos. Espera a que termine (2-3 minutos)
Paso 4: Cuando veas ✅ "INSTALLATION COMPLETE!", presiona cualquier tecla
Paso 5: Abre tu navegador y ve a:
http://localhost:3000

¡Eso es todo! ✨

🔧 OPCIÓN 2: Manual (Si INSTALAR.bat No Funciona)

Abre PowerShell como Administrador y copia cada comando.
Comando 1:
Copy-Item ".env.example" ".env"
Comando 2:
docker-compose build
(Espera 2-3 minutos)
Comando 3:
docker-compose up -d
Comando 4:
Start-Sleep -Seconds 10
Comando 5:
docker-compose ps

Luego abre: http://localhost:3000

📋 Requisitos

  • ✅ Docker Desktop instalado en Windows

❓ Problemas Comunes

❌ "docker" no se reconoce
Solución: Reinicia tu PC después de instalar Docker
❌ Puerto 3000 ya en uso
Solución: Cierra otras aplicaciones que usen ese puerto
❌ Servicios no arrancan
Solución: Abre PowerShell y escribe:
docker-compose logs
